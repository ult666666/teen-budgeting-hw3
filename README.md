# Teen Budgeting — HW3
Individual coursework for Charles Dai, 70-445, Fall 2026.

## Provenance
The original October 1 static app is preserved separately in TeenBudgetingSubmission.
This repository imports that app and the official Starter C specs retrieved from Canvas on October 15. The original app implements only a small part of the full spec.

## Plan
Complete R-05 spending entries, editing and deletion with tests first. Add an ephemeral server-memory demo using a typed display name. Close SEC-18 input validation and keep unmet audit requirements visible. Publish only reviewed source files; preserve real evidence, never backdate it.

## Current baseline
Open index.html; run `node tests/test.js` for the original eight assertions. This import is not the finished HW3 build.

## Non-goals
No real payments, identity provider, database or model calls. Use fictional spending only. Server-memory demo state resets on deploy, restart or instance change and is not suitable for real budgets.

## AI use
ChatGPT assists with development, testing, deployment and drafting. Student manual checks and reflection are not claimed complete without student review.
